# Volunteer Dashboard

A React + Vite dashboard UI for volunteer metrics, with a login page, metric cards and an admin view.

## Context

Part of the Didar volunteer management work.

## Features

- Login page
- Dashboard with metric cards
- Admin page

## Tech stack

- **Frontend:** React, Vite

## Getting started

```bash
npm install
npm run dev
```
